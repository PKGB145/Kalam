Setup (2 minutes):
1. Go to console.cloud.google.com
2. Create a project → Enable Google Calendar API
3. APIs & Services → Credentials → Create OAuth 2.0 Client ID
4. Application type: Web application
5. Authorised JavaScript origins: add null (for local file) or your domain
6. Go to OAuth consent screen → add your Google email under Test users
7. Paste the Client ID above and click Connect

⚠ Getting 'Service unavailable'? Your Google account must be added as a Test User in the OAuth consent screen of your Cloud project.
